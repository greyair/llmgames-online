# Pokemon Showdown animation subset

Source: https://github.com/smogon/pokemon-showdown-client/tree/eeaec53202425be20761198da837f5fb9b264c51/play.pokemonshowdown.com

Generated by scripts/pokemon/vendor-showdown.mjs. Original scene effect methods, easing functions, Sprite implementation, all shared/status animations, and the 165 Gen 1 move definitions plus their dependencies. Type annotations and unused client UI are removed; move callbacks are not rewritten.

Move definitions: CC0-1.0. Renderer: MIT. Preserve the licensing notice at the top of upstream.js, including asset exceptions. Effects are served locally. The surrounding client is not imported.

The modular battle UI uses the original locally served raster effect assets in `/pokemon/showdown/fx/`, with upstream move-specific backgrounds, timing, and trajectories. The adapter preserves our battlefield layout and sprite proportions. Regeneration writes into `src/game-ui/pokemon/showdown/`.
