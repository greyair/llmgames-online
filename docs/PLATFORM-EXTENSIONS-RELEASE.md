## 3. 发布时补的两处

1. **`/api/v1/mcp/info` 的工具清单漏了聊天工具。** 那份 `tools.core` 是手写的，聊天作为两个真工具上线后它仍列 17 个。已在生产核对时发现，补成 19 个，并加了用例：`info.tools.core` 必须与 `ai-spec.json`（由真实 MCP server 生成）逐项相等，以后不会再悄悄漂移。
2. **MCP 版本号从 `0.9.0` 提到 `0.10.0`。** 工具面变了（17 → 19），宿主按这个字符串缓存工具列表，不升就等于让老宿主继续用旧清单。

## 5. 没验到的

- **没有真人开过一局带聊天/Bot 的对局。** 登录要 OAuth 人工授权，脚本进不去。聊天、选项、Bot、恢复动作都有房间级与 MCP 级用例，但没有一次真实浏览器 + 外部 Agent 的混合对局。
- **Bot 在线上只跑过测试环境。** 暂停/恢复路径带用例，真实 DO 的 150ms 唤醒链在线上没有观测数据。
- **15 分钟以上的长局与回放**没有在生产复测。

建议的上线后第一次人工验收：开一局五子棋加两个 Bot（看是否自己下完）、开一局 19 路围棋（看棋盘是否铺满）、在房间发一条 @ 消息（看 AI 能否读到最新那条）。
